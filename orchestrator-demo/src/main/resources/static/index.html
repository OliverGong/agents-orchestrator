编辑场景

控制平面状态 version —

Agent 的 system prompt / 模型 / 温度 / 校准规则均可在运行时编辑并立即热生效（逐次调用读取）。

工作流编排（模板热切换）

阶段按声明顺序执行/校验（依赖必须位于其前）；同一依赖波次内的阶段在 CONCURRENT 模式下并行执行并合并结果。 保存时后端按各 Agent 的槽位契约校验逻辑闭环：输入槽位必须由前置阶段/更早波次产出，或被该 Agent 声明为 pending-safe（卡片中 ⟂ 标注），否则返回 400。

MCP 服务器

连接由后端注册表动态维护：Streamable HTTP 为默认传输（SSE 已弃用、STDIO 启动本地子进程并继承当前环境变量），保存后自动按配置差异重建连接；映射到 Agent 的服务器，其工具会注入该 Agent 的每次模型调用，调用详情（服务器/工具/耗时/结果）可在「运行回放」详情中查看。状态 15s 自动重试，失败可手动重连。
